# Jinyu — 3D Creator

A responsive 3D creator portfolio built with React, TypeScript, Tailwind CSS, Framer Motion, Lucide React, and Vinext.

## Local development

```bash
npm install
npm run dev
```

## Replace the hero portrait

1. Add a transparent PNG or WebP portrait to `public/`, for example `public/jinyu-portrait.png`.
2. Open `app/page.tsx` and change `PORTRAIT_URL` to `/jinyu-portrait.png`.
3. If needed, adjust `.hero-portrait` width and position in `app/globals.css`.

For the cleanest result, use a transparent-background image with the subject centered and at least 1200 px tall.
